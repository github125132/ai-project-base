# GAP 模块开发计划

> 基于《中药材GAP检查指南》(2023年6月) 和已设计的66张数据库表
> 制定模块化、可并行的开发计划

---

## 一、总体架构

```text
后端: yudao-module-gap (新增模块)
管理端: src/views/gap/ (新增目录)
移动端: src/pages/gap/ (新增目录)
```

### 模块依赖关系

```text
阶段0 框架搭建
    ↓
阶段1 基础数据 (基地/地块/品种/种子) ─┐
阶段2 投入品管理                       │
阶段3 农事活动管理                      │
    ↓                                  │
阶段4 采收加工管理 ────────────────────┤
    ↓                                  │
阶段5 质量检测管理                      │
阶段6 仓储物流管理                      │
    ↓                                  │
阶段7~12 支撑模块 ─────────────────────┘
    ↓
阶段11 溯源管理 (依赖前面所有模块)
```

## 二、开发阶段划分

### 阶段0: 框架搭建 (P0)

**目标**: 创建后端模块、管理端目录、初始化字典数据

| 任务 | 说明 | 涉及仓库 |
|------|------|----------|
| 创建 yudao-module-gap | pom.xml、包结构、模块注册 | server |
| 创建管理端 gap 目录 | API、页面、路由 | admin-web |
| 创建移动端 gap 目录 | 页面、API | uniapp |
| 初始化系统字典 | 基地状态、地块状态、农事类型、投入品类别、检验类型等 | server |
| 初始化错误码 | GAP模块错误码常量 | server |

**系统字典清单**:

| dict_type | 用途 |
|-----------|------|
| `gap_base_status` | 基地状态:正常/停用 |
| `gap_plot_status` | 地块状态:空闲/种植中/休养 |
| `gap_seed_type` | 种子类型:种子/种苗 |
| `gap_seed_source` | 种源来源:自繁/外购/野生采集 |
| `gap_seed_status` | 种子状态:待验/合格/不合格/已使用 |
| `gap_input_category_type` | 投入品大类:农药/肥料/生物制剂/其他 |
| `gap_input_product_status` | 投入品状态:正常/停用 |
| `gap_farming_type` | 农事类型:整地/播种/育苗/移栽/中耕/除草/灌溉/施肥/整枝/覆盖/病虫害防治/采收 |
| `gap_farming_status` | 农事记录状态:草稿/已提交/已审核 |
| `gap_harvest_status` | 采收状态:已采收/已运送/已加工 |
| `gap_process_status` | 加工状态:加工中/已完成/检验中 |
| `gap_drying_method` | 干燥方式:晒干/阴干/烘干/风干 |
| `gap_storage_area_type` | 仓库分区:待验区/合格区/不合格区/退货区/发货区 |
| `gap_quality_status` | 质量状态:待验/合格/不合格 |
| `gap_inspect_type` | 检验类型:性状/鉴别/检查/含量测定/农残/重金属 |
| `gap_inspect_conclusion` | 检验结论:合格/不合格/未检 |
| `gap_document_type` | 文件类型:质量手册/程序文件/SOP/记录表单/技术标准/管理制度 |
| `gap_doc_status` | 文件状态:草稿/审核中/已批准/已废止 |
| `gap_training_type` | 培训类型:新员工/在岗/转岗/晋升/继续教育 |
| `gap_audit_type` | 审核类型:内部审核/管理评审/专项检查 |
| `gap_nc_type` | 不符合类型:一般/严重 |
| `gap_nc_status` | 不符合项状态:待整改/整改中/待验证/已关闭 |
| `gap_change_type` | 变更类型:基地/品种/工艺/设备/人员/SOP/供应商 |
| `gap_transport_status` | 运输状态:待运输/运输中/已送达/异常 |
| `gap_trace_status` | 追溯状态:种植中/已采收/已加工/已入库/已放行/已出库/已销售 |

### 阶段2: 投入品管理 (P0)

**目标**: 投入品全生命周期管理，禁用农药拦截

| 表名 | 功能 | 管理端页面 |
|------|------|-----------|
| `gap_input_category` | 投入品分类树 | 分类管理 |
| `gap_input_product` | 投入品产品(含禁用标识) | 产品列表、产品详情 |
| `gap_input_supplier` | 供应商档案 | 供应商列表 |
| `gap_input_inventory` | 投入品库存 | 库存列表 |
| `gap_input_use_record` | 使用记录(安全间隔期校验) | 使用记录列表 |
| `gap_waste_disposal` | 废弃物处理 | 废弃物处理列表 |

**关键业务规则**:
- 禁用农药(`is_banned=1`)使用时系统拦截
- 安全间隔期自动计算最早采收日期
- 投入品库存自动扣减

## 三、每阶段交付标准

### 后端交付

- [ ] DO 类（继承 BaseDO，含完整字段和注释）
- [ ] Mapper 接口（继承 BaseMapperX）
- [ ] Service 接口和实现（含 CRUD + 业务校验）
- [ ] Controller（含 Swagger 注解、权限控制 @PreAuthorize）
- [ ] VO 类（PageReqVO、SaveReqVO、RespVO）
- [ ] 枚举类（状态、类型等）
- [ ] 错误码（ErrorCodeConstants）
- [ ] 单元测试（create_tables.sql / clean.sql）

### 管理端交付

- [ ] API 接口文件（TypeScript）
- [ ] 列表页（index.vue）
- [ ] 表单页（Form.vue）
- [ ] 详情页（Detail.vue，可选）
- [ ] 路由配置
- [ ] 菜单配置

### 移动端交付（关键模块）

- [ ] 列表/详情页
- [ ] 现场操作页（拍照、定位）
- [ ] API 对接

## 五、开发顺序约束

1. **阶段0必须先完成**（模块框架）
2. **阶段1必须先于阶段2~6**（基础数据被所有业务模块依赖）
3. **阶段4必须先于阶段5~6**（加工后才能检验和入库）
4. **阶段1~6必须先于阶段11**（溯源依赖全链条数据）
5. **阶段7~10可并行**（支撑模块，相互独立）
6. **阶段12贯穿全程**（日志随业务模块同步开发）
