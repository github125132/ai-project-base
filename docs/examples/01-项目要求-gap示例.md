# 项目要求

## 1. 项目定位

中药材GAP基地全流程服务平台面向中药材规范化种植基地、药企供应商管理、监管延伸检查、GAP评审迎检和公众溯源展示。

平台以GAP合规建设为主线，围绕基地、地块、农事、文件、检测、培训、迎检、申报、基源鉴定与种子管理，形成多端协同的数字化服务能力。

视觉与产品气质：

- 专业合规
- 政务级可信
- 药企认可
- 科技清爽
- 绿色中药材主题

## 4. 业务模块

### GAP基地管理

- 基地基础信息、负责人、质量负责人、基地面积、建设年限
- GIS地图展示地块分布
- 地块编号、品种、面积、播种日期、状态
- 地块详情、农事记录、检测报告联动查看

### GAP文件管理

- 质量手册、程序文件、SOP、记录、表单等目录化管理
- 文件状态：未编辑、已编辑、已审核、已归档
- 支持预览、编辑、下载、打印、版本记录
- 支持导出全套GAP文件胶装版

### 溯源管理

- 批次列表、品种、地块、状态管理
- 展示种源、播种、施肥、植保、采收、加工、仓储、出库等过程信息
- 支持生成溯源码
- 支持公众、药企、监管多视角预览

### 检测管理

- 检测类型：土壤、灌溉水、加工用水、种子、成品药材
- 报告信息：检测机构、日期、项目、结果、合格/不合格
- 超标标红、合格标绿
- 支持导出迎检用检测报告合集

### 培训管理

- 课程类型：法规、SOP、内审、迎检
- 学习记录：人员、时长、成绩、证书
- 自动归档培训档案

### 评审迎检管理

- 内部符合性评审
- 药企供应商评审
- 药监局延伸检查
- 检查要点清单、证据上传、整改闭环
- 一键生成迎检材料包

### 申报材料汇编

- 官方目录结构自动生成
- 材料状态：缺失/齐全
- 一键打包PDF、Word和打印册
- 自动生成封面、目录、页码、胶装格式

### 基源鉴定与种子管理

- 基源鉴定：照片、DNA条形码、鉴定报告、青码链
- 种子管理：来源、检疫证、批次、发芽率、处理记录
- 一品种一档，防止混杂

## 5. 多端范围

| 端 | 目标用户 | 重点 |
|----|----------|------|
| PC管理后台 | 管理员、基地运营人员、质量负责人 | 完整业务管理、状态闭环、材料导出 |
| 手机APP | 现场人员、移动办公人员 | 拍照、定位、扫码、时间留痕、现场操作效率 |
| 大屏驾驶舱 | 展示大厅、管理驾驶舱 | 基地态势、环境数据、检测结果、迎检状态 |
| 溯源H5 | 公众、药企、监管人员 | 可信展示、快速查看、多视角信息深度 |
| 公示标识物料 | 基地现场人员和外部检查人员 | 公示牌、地块牌、区域警示牌 |

## 6. 基础开发要求

- 代码中的类名、变量名、接口字段使用英文
- 用户可见内容必须使用中文，包括Web、uniapp、H5、大屏、导出文件
- 状态码、枚举名、英文编码不得直接展示给用户
- 后端禁止魔法数，状态判断和状态更新必须基于枚举或系统字典
- 涉及状态、类型、结论、阶段的接口应返回机器值和中文展示名，例如 `status` + `statusName`
- 业务字段注释、Swagger说明、校验提示、错误提示使用中文
- 一项功能完成后，应按涉及仓库分别提交推送

## 7. UI原则

- 主题色以绿色中药材、合规政务、清爽科技为基础
- 管理端强调信息密度、状态清晰、操作闭环
- APP端强调现场操作效率，支持拍照、定位、时间留痕
- 大屏端强调远距离阅读清晰和异常状态醒目
- H5端强调可信、清爽、移动端优先
