# 项目开发进度总览

本文档用于记录 {{PROJECT_NAME_CN}} 的总体开发进度。详细设计、开发记录和验证记录放在 `docs/progress/` 子目录中。

> 本仓为通用基线项目模板。新项目首次接手时,请按 [`00-项目初始化引导.md`](./00-项目初始化引导.md) 完成初始化后,再清空本文件并按本项目实际情况填写。
> 原 GAP 示例排期与子文档保留在 `docs/examples/` 仅供参考。

## 维护规则

- 每次完成阶段性工作后,同步更新本文档的整体状态、模块进度和最近变更
- 每个业务功能、跨端能力或基础设施变更,应在 `docs/progress/` 下建立一篇子文档
- 总览只写结论和当前状态,详细设计、接口、表结构、页面、验证结果写入对应子文档
- 状态统一使用:未开始、设计中、开发中、联调中、已完成、暂停
- 日期使用 `YYYY-MM-DD`
