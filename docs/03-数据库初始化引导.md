# 数据库初始化引导

## 1. 目标

本文用于指导新环境创建 中药材GAP基地全流程服务平台 后端数据库,让 `ai-project-server` 可以连接 MySQL 并启动。

> 所有连接地址、账号、密码均通过环境变量或本地配置文件管理,**不在文档与代码仓中明文出现**。模板见根目录 `.env.example`。

## 2. 数据库要求

- MySQL 8.0+
- 字符集:`utf8mb4`
- 排序规则:`utf8mb4_unicode_ci`
- 时区:`Asia/Shanghai`

## 3. 环境变量

复制根目录 `.env.example` 为 `.env`,按实际环境填写:

```dotenv
MYSQL_HOST=<数据库主机>
MYSQL_PORT=3306
MYSQL_DATABASE=gap
MYSQL_USERNAME=<数据库账号>
MYSQL_PASSWORD=<数据库强密码>
```

`.env` 已纳入 `.gitignore`,严禁提交。

## 4. 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS gap
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

如需独立业务账号:

```sql
CREATE USER IF NOT EXISTS 'gap'@'%' IDENTIFIED BY '<强密码>';
GRANT ALL PRIVILEGES ON gap.* TO 'gap'@'%';
FLUSH PRIVILEGES;
```

## 5. 初始化表结构和基础数据

MySQL 初始化脚本位于:

```text
ai-project-server/sql/mysql/gap-tables.sql
```

> 若该路径下尚未生成项目专用 SQL,请参考 ruoyi-vue-pro 原始脚本(通常名为 `ruoyi-vue-pro.sql`),复制并改名为 `gap-tables.sql` 后追加业务表。该过程应记录到 `docs/progress/`。

导入示例:

```bash
mysql -h "$MYSQL_HOST" -P "$MYSQL_PORT" -u "$MYSQL_USERNAME" -p "$MYSQL_DATABASE" < ai-project-server/sql/mysql/gap-tables.sql
```

## 6. 后端配置文件

后端按 Spring Profile 划分:

```text
ai-project-server/yudao-server/src/main/resources/application.yaml          # 公共配置
ai-project-server/yudao-server/src/main/resources/application-local.yaml    # 本地开发(不提交真实密码)
ai-project-server/yudao-server/src/main/resources/application-dev.yaml      # 内网开发
```

公共配置关键项:

```yaml
spring:
  application:
    name: ai-project-server
  profiles:
    active: local

yudao:
  captcha:
    enable: false
  tenant:
    enable: false
```

数据源应通过占位符引用环境变量,而非写入明文:

```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://${MYSQL_HOST}:${MYSQL_PORT}/${MYSQL_DATABASE}?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&nullCatalogMeansCurrent=true&rewriteBatchedStatements=true
          username: ${MYSQL_USERNAME}
          password: ${MYSQL_PASSWORD}
```

含真实密码的 `application-local.yaml` 必须被忽略,只提交 `application-local.yaml.example` 模板。

## 7. Redis 要求

ruoyi-vue-pro 默认依赖 Redis:

```yaml
spring:
  data:
    redis:
      host: ${REDIS_HOST:127.0.0.1}
      port: ${REDIS_PORT:6379}
      password: ${REDIS_PASSWORD:}
      database: ${REDIS_DATABASE:0}
```

## 8. 启动前检查

- JDK 17 可用
- Maven 可用
- MySQL `gap` 数据库已创建
- `gap-tables.sql` 已导入
- Redis 已启动
- `application-local.yaml` 已按本机环境填写,或环境变量已注入
- 多租户已关闭:`yudao.tenant.enable=false`
- 图片验证码已关闭:`yudao.captcha.enable=false`

## 9. 常见问题

### 连接失败

- 主机/端口是否可达
- 账号密码是否正确
- 用户是否拥有 `gap` 库权限
- 防火墙是否放行端口

### 表不存在

确认 `ai-project-server/sql/mysql/gap-tables.sql` 已成功导入。

### 多租户报错

首版按单组织部署,默认关闭多租户。若后续启用,需补充租户、租户套餐、菜单权限等初始化数据。
